# PHP Задания 1

Этот репозиторий содержит решения для трех заданий на PHP.

## Задание 1: Генерация чисел и проверка на простое число

### Описание
- Функция `generateNumbers` генерирует массив чисел между двумя границами.
- Функция `isPrime` проверяет, является ли число простым.
- Ввод данных осуществляется через HTML-форму.

### Как использовать
1. Запустите `Задание 1.php` 
2. Введите начальное и конечное числа, а также число для проверки на простоту.
3. Нажмите "Отправить".

---

## Задание 2: Вывод чисел с цветами

### Описание
- Выводит числа от 1 до 50.
- Если число делится на 3, оно отображается зеленым цветом.
- Если число делится на 5, оно отображается красным цветом.
- В остальных случаях число отображается черным цветом.

### Как использовать
1. Запустите `Задание 2.php`

## Задание 3: Фильтрация клиентов

### Описание
- Фильтрует клиентов по городу и минимальному рейтингу.
- Данные клиентов хранятся в массиве.
- Ввод данных осуществляется через HTML-форму.

### Как использовать
1. Запустите `Задание 3.php`
2. Введите город и минимальный рейтинг.
3. Нажмите "Фильтровать".
