Задание 1
Напишите PHP код со следующими функциями:
Функция “generateNumbers” - принимает два числа (нижнюю и верхнюю границу) в качестве аргументов и возвращает массив чисел между этими границами. Например, generateNumbers(1, 5) должен вернуть массив [1, 2, 3, 4, 5].
Функция “isPrime” - принимает число в качестве аргумента и возвращает true, если число является простым, и false в противном случае. 
Ввод данных должен быть выполнен с помощью формы.

Задание 2
Напишите PHP код, который будет выводить все числа от 1 до 50 включительно. Если число делится на 3, то его нужно вывести зеленым цветом, а если делится на 5, то красным. В противном случае, число выводится черным цветом.


Задание 3

Вам дана база данных с информацией о клиентах компании, где каждый клиент представлен ассоциативным массивом с полями: имя (name), город (city), рейтинг (rating) и дата регистрации (registration_date).
Необходимо написать скрипт PHP, который будет выполнять следующие фильтрацию клиентов по рейтингу и городу (например, вывести только клиентов с рейтингом > 4 из города “Москва”).

Данные пользователей, хранящиеся на сервере:

$clients = array(
array('name' => 'Иван', 'city' => 'Москва', 'rating' => 5, 'registration_date' => '13.01.2020'),
array('name' => 'Петр', 'city' => 'Санкт-Петербург', 'rating' => 4, 'registration_date' => '30.03.2001'),
array('name' => 'Сергей', 'city' => 'Нижний Новгород', 'rating' => 3, 'registration_date' => '02.7.2015')
);

Фильтр должен быть оформлен с помощью html-формы с использованием input с типами "text", "checkbox" и "date".
Вывод данных должен быть оформлен так, чтобы он был понятен рядовому пользователю.
